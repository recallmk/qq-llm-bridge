# QQ LLM Bridge

两个独立的 QQ 机器人桥接项目，分别对接 DeepSeek Harness 和 Antigravity（Gemini）。它们使用 NapCat 的 OneBot v11 WebSocket，各自拥有独立配置与会话数据。

- [DeepSeek 桥接](deepseek/README.md)：安装与配置步骤见该目录。
- [Gemini / Antigravity 桥接](gemini/README.md)：安装与配置步骤见该目录。

本仓库仅整理源码和必要的第三方源码，不包含 QQ 登录资料、模型账号、消息记录、运行数据、表情图片或本机软件。安装依赖后分别配置；两个实例同时使用时请分配不同的端口和账号数据目录。

第三方来源和许可参见 [THIRD_PARTY_NOTICES.md](deepseek/THIRD_PARTY_NOTICES.md)。
