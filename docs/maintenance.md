# 项目维护与本机数据

在仓库根目录维护 `ds-QQ` 和 `gemini-QQ`，运行配置按各自文档设置。`qq-src/vendor/dsh-fish` 保存 Gemini 使用的共享源码；`gemini-QQ/bridge/vendor/dsh-fish` 是本机联接，部署时需按 Gemini 文档建立。

运行配置、API 密钥、QQ 登录资料、会话与聊天记录、运行日志、缓存、二进制依赖和迁移保留数据均不提交到 Git。迁移保留目录只用于本机核对和恢复；不能用它覆盖正在运行的账号数据。提交前用 `git status` 检查变更，确保不包含私有数据。

## QQ 数据和兼容联接

DS 的启动器把 QQ 漫游资料目录设置到项目的 `ds-QQ/data/qq-user`；Gemini 的启动器使用独立的 `gemini-QQ/profile` 和 `gemini-QQ/qq-native-data`。这些目录都属于本机私有数据。

旧安装可能保留指向本机数据的兼容联接，例如系统漫游目录里的 `QQ`、旧盘符的 `QQ` 入口。迁移或删除旧盘目录前，先确认联接最终目标和每个 QQ 账号当前使用的数据位置，并在实例停止后核对数据；不要把联接目标或账号资料提交到 Git。不能仅凭启动器中的路径认定 QQ 原生数据已经不再使用旧入口。
